PaQueueKa

A mobile-first queue and match management system for badminton and pickleball

Overview

PaQueueKa is a production-grade React Native app that transforms how badminton and pickleball communities manage their sessions. Built for mobile-first play, it handles queue management, match scheduling, and player analytics in real-time.

Key Features

  • Session Management Hosts create sessions; players join via invite code or QR scan
  • Smart Queue System Automatic rotation with balance consideration and partnership tracking
  • Player Rankings Bayesian-adjusted skill tiers and win-rate analytics
  • Offline-First Design Full queue management works offline; syncs automatically on reconnect
  • Dark Mode Seamless theme switching with Forest palette adaptation
  • Analytics & History Detailed match records, performance trends, and club statistics

Technology Stack

Mobile React Native / Expo
Backend Supabase / PostgreSQL
Language TypeScript
State Zustand + AsyncStorage
Navigation Expo Router
Realtime Postgres Changes
